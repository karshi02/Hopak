ผลกระทบ
ผู้มีสิทธิ์ฝ่ายการเงินหรือคำขอซ้ำจากระบบสามารถให้สองคำขออ่านยอดค้างชุดเดียวกัน แล้วส่ง payout จริงสองครั้งก่อนคำขอใดเปลี่ยนสถานะ ส่งผลให้เงินออกเกินยอดที่ควรจ่าย

การตรวจสอบอย่างปลอดภัย
ใช้ test double ของ gateway แล้วส่งคำขอโอนสองคำขอพร้อมกันสำหรับ dorm ทดสอบเดียวกัน; test ต้องยืนยันว่ามีการเรียก gateway ได้ไม่เกินหนึ่งครั้งและสถานะบัญชีถูกเปลี่ยนอย่าง atomic

คำแนะนำ
ทำ reserve/claim payment ที่จะโอนด้วย transaction หรือ conditional update ก่อนเรียก gateway, เก็บ payout attempt ที่มี unique idempotency key ตามชุด payment, และคืนสถานะ/ทำ reconciliation หาก gateway ล้มเหลว
