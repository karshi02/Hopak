ขั้นตอน deploy ที่ทำจริง
--------------------------------------------------------
1. git pull origin main (บน /opt/hopak)
2. docker compose -f docker-compose.prod.yml up -d --build
   → build api+web สำเร็จ, สร้าง volume docker_api_private (D3), คอนเทนเนอร์ขึ้นครบ
3. prisma migrate deploy — ครั้งแรกพลาด "Could not find Prisma Schema"
   สาเหตุ: WORKDIR คอนเทนเนอร์ = /app แต่ schema อยู่ /app/apps/api/prisma
   แก้: รันจาก apps/api → cd apps/api && npx prisma migrate deploy
   ผล: apply 7 migrations สำเร็จ (add_user_email_otp + 6 ตัวใหม่) DB sync
4. แก้ role คนเก่า [43]: SELECT เจอ 0 rows / UPDATE 0 = ไม่มีใครโดนบั๊กบน prod

บทเรียนสำหรับ deploy ครั้งหน้า (กันพลาดซ้ำ)
--------------------------------------------------------

  (npx prisma จาก /app จะโหลด 7.9.1 มาผิดเวอร์ชัน — รันจาก apps/api ถึงเจอตัวถูก)
